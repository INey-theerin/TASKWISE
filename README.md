# TaskWise Prototype

เปิด `index.html` เพื่อใช้ Interactive Prototype หรือเปิด `wireframe.html` เพื่อดูโครงหน้าจอขาวดำ ทั้งสองแบบใช้ Flow เดียวกัน สลับรูปแบบได้ด้วยปุ่มด้านบน ไม่ต้องติดตั้งโปรแกรมหรือเชื่อม Google Drive

ต้นแบบอิงส่วน Functions & Features ใน Ideate.docx ซึ่งครอบคลุม 5 Functions รวม Focus & Motivation รายการ Idea Selection ในเอกสารมีขอบเขตแคบกว่า จึงยึดรายการฟังก์ชันฉบับท้ายเพื่อให้ต้นแบบครอบคลุม

## ฟีเจอร์และเส้นทางใช้งาน

| Function | Features | เส้นทาง |
|---|---|---|
| Priority Management | Smart Priority, Priority Score, Deadline / Score Ranking | เพิ่มงาน → กรอกข้อมูล → ลำดับความสำคัญ → อ่านเหตุผล → เปลี่ยนวิธีเรียงหรือเลื่อนลำดับ |
| Time Planning | Time Balance Planner, Time Estimator, Workload Calendar | แก้เวลาประเมินในงาน → ตั้งเวลาว่าง → เพิ่มช่วงทำงาน → ตรวจปฏิทินและชั่วโมงรวม |
| Task Breakdown | Subtasks, Checklist, Progress Tracker | ดูงานย่อย → เพิ่มขั้นตอน → ติ๊กเสร็จ → ตรวจเปอร์เซ็นต์ → ปิดงาน |
| Workload Monitoring | Overload Alert, Schedule Conflict Checker, Smart Reminder | ดูคำเตือน → ปรับช่วงทำงาน → ตรวจคำเตือนใหม่ → เปิดงานจากการแจ้งเตือน |
| Focus & Motivation | Focus Mode & App Blocker, Smart Break, Study Streak, Achievement Badges | เลือกงาน → เลือกสิ่งรบกวนจำลอง → เริ่ม → หยุด/ทำต่อ → ครบเวลา → พัก → ตรวจความสม่ำเสมอและรางวัล |

## โจทย์ทดสอบ

ให้ผู้ทดสอบกดเองและเล่าความคิดระหว่างทำ ผู้ดำเนินการอ่านเฉพาะภารกิจ ไม่บอกลำดับปุ่มก่อนเริ่ม รีเซ็ตข้อมูลก่อนเปลี่ยนผู้ทดสอบ

1. เพิ่มรายงานวิชาใหม่ ส่งพรุ่งนี้ คะแนน 20 ความยาก 4 ใช้เวลา 3 ชั่วโมง แล้วเลือกงานที่จะเริ่มก่อน พร้อมอธิบายเหตุผล
2. แบ่งงาน HCI เป็นสองช่วง ช่วงละ 60 นาที ภายในวันส่ง ตรวจว่าเวลาที่จัดไว้ตรงกับที่ต้องการ
3. เพิ่มงานย่อยให้ HCI แล้วทำรายการย่อยให้ครบและปิดงาน
4. แก้ตารางตัวอย่างวันนี้ให้ไม่มีเวลาซ้อนและไม่เกิน 3 ชั่วโมง โดยแบ่งงานไปวันอื่นก่อนถึงกำหนดส่ง ควรรีเซ็ตก่อนภารกิจนี้เพื่อให้ชุดคำเตือนเหมือนกันทุกคน
5. เริ่มโฟกัส 25 นาที เลือกบล็อกโซเชียลจำลอง หยุดชั่วคราวแล้วทำต่อ ใช้ปุ่ม “จำลองครบเวลา” ในตัวควบคุมทดสอบ เริ่มพัก และดูรางวัลที่ได้รับ

## ขอบเขตการจำลอง

- ข้อมูลตัวอย่างทั้งหมดเป็นข้อมูลสมมติ ยังไม่มีผลทดสอบผู้ใช้จริง
- คะแนนลำดับความสำคัญเป็นสูตรสาธิตที่แสดงเหตุผลในหน้า Priority ยังไม่ได้ปรับเทียบด้วยงานจริง
- เวลาประเมินมาจากผู้ใช้ ไม่ใช่การทำนายอัตโนมัติ
- การแจ้งเตือนแสดงภายในแอป ไม่ส่ง Push หรืออีเมล
- App Blocker จำลองการเลือกและสถานะเท่านั้น ไม่บล็อกแอปหรือเว็บไซต์จริง
- ปุ่มจำลองครบเวลาทำให้บันทึก Streak และ Badges ได้เพื่อทดสอบโดยไม่รอ 25 นาที
- ข้อมูลเก็บในเบราว์เซอร์นี้เท่านั้น ไม่ซิงก์ข้ามเครื่อง ตัวจับเวลาไม่ทำงานต่อเมื่อปิดหน้าเว็บ
- รองรับการแก้วันและเวลาโดยฟอร์ม ไม่มี Drag & Drop เพราะไม่ได้อยู่ใน Features ที่เลือกท้ายเอกสาร
